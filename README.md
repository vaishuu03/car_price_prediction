A machine learning project that predicts the selling price of a used car based on features such as brand, model, year, mileage, fuel type, transmission, and other relevant attributes.

Buying or selling a used car can make it difficult to determine a fair market price. This project uses historical car data and machine learning techniques to build a model capable of estimating a car's price from its characteristics.

The project covers the complete machine learning workflow:

Data collection and exploration

Data cleaning and preprocessing

Exploratory Data Analysis (EDA)

Feature engineering

Model training

Model evaluation

Price prediction
